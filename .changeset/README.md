# Changesets

Hello and welcome! This folder is generated and maintained by Changesets, a
tool for managing package versions and changelogs in multi-package repositories
and single-package projects.

Run `pnpm changeset` after making a publishable change. The command records the
affected package, semantic version bump, and changelog summary in a Markdown
file in this directory.

Learn more in the [Changesets documentation](https://github.com/changesets/changesets).
